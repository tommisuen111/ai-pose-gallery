# P03 人物表情：计数、合成台与指南

静态站点，未部署、未合并。作者署名、既有 `*.pages.dev` 图片地址和授权说明保持原样。

## 计数

人物表情库的导航数字来自 `data/face-zh.json`，经 `countFaceCatalog()` 计算，不再使用写死的 `500+`。

- **可浏览词条：328。** 每个分类里的每一行「提示词 + 中文」算 1 条。这是侧栏、表情库页眉和指南里的总数，也等于不筛选时页面上能逐条复制或加入配方的行数。
- **不重复提示词：280。** 有 31 个英文提示词跨分类重复，多出来 48 行。同一分类内没有重复提示词，所以 328 行都会渲染。
- **例图位：247。** 其中 238 个图片文件不重复；有 9 张图被「轻微愠怒」和「轻蔑厌恶」各引用一次，两个分类里都能点开。
- 体系或搜索只改「当前显示」。词库 328 在筛选后仍保留；有搜索时分类按钮显示「当前命中/该体系词条数」，例如 `3/44`，不会把筛选结果写成词库总数。

## 合成台

顺序为：参考图 → 人物角色身材 → 人物表情 → 模型与参数 → 提示词。

表情沿用身材标签的做法：图库「加入配方」、合成台手动输入、删除与清空都会写入 `recipe.faceTags`，并随配方保存在本地。提示词先写身材行，紧接着写表情行。复制、导出 ComfyUI 工作流、生成和重置提示词都使用这份文本。清空配方会同时清掉身材和表情。

身材与表情标题后面各有一个入口，分别前往 `/body` 和 `/face`。跳转走现有路由，合成配方留在内存和本地存储里。

## 验证

`pnpm test` 覆盖词条计数、筛选不改写总数，以及表情行排在身材行之后。`pnpm build` 含类型检查。
